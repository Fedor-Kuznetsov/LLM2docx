# LLM2docx

Программа в первую очередь предназначена для переноса структуры отчета, формул и минимального форматирования, близкого к требованиям ГОСТ 7.32-2017.

Передать промпт в LLM из `prompt.txt`, описать содержание отчета и требования к форматированию.

В `report.txt` добавить ответ, который предоставила LLM.

Установить requirements:
`pip install -r requirements.txt`

Запустить скрипт `convert.py`.

В директории появится файл в формате .docx с указанием даты и времени генерации.

Код проверялся на python 3.10.0.
